# models: trusted models of real libraries

A **model** here is an executable stand-in for a real library: a program's proof runs over the
model in place of the library. Where the model is code, it is verified (translated by Goose and
proved, or generated by a trusted generator); what is trusted is only its claim to **behave like
the library** it replaces, and every model keeps the evidence for that claim beside it. This
directory is the Go module `models.lab`, a path that names no project using it (the part `Net/`,
which holds its Lean, is exported to dsverify-lab: `notes/decisions.md`, "Shared Go runtime under a
neutral module path"). Translated by goose project `models` (`etc/goose.py`, lean root
`models.lab=Net`: `Net/{Code,GeneratedProof,Spec,Proof}/models_lab/`), trust base
`etc/tcb-collections/models.txt`. Checked by `etc/gates.sh` (section `models`).

Layout: a model's Go package at the top (`pbcodec/`, `jsoncodec/`, `pbdesc/`, `rpcdesc/`), its
generator in a directory named for the library (`protobuf/`, `json/`, `net/rpc/`), its differential
tests in `internal/`. A model of a library is a first-class Go package (`notes/decisions.md`, "Models
are first-class Go packages"): it starts from the real library's source and keeps its API, the places
it changes marked `MODEL:`; its difference from the library is computed, not stored: `diff.py MODEL
[--stat]` (e.g. `net/rpc`). A model of a standard-library package lives at its import path
(`net/rpc/`, `net/http/`, in the module `net/go.mod` that nothing builds) and builds in place of the
real package through `goroot.py` (`overlay`: a `go build -overlay` file, with `-tags netmodel` for a
program's generated registration; `farm`: a GOROOT of links, for goose, a project's `std_models` in
`etc/goose.py`). Where a model does not model the library it panics with a value that has a
`NotModelled` method.

## The other kinds of trusted model

Kept where Perennial's layout puts them, not here:

- `TrustedCode/<pkg>.lean` (and a part's `<root>/TrustedCode/`): hand-written GooseLang models of
  the declarations a Goose configuration lists as `trusted`; each docstring says why it is faithful
  (`etc/tcb-report.py`'s "Not checked by Lean").
- `GooseLang/Ext/<Name>/Impl.lean`: the trusted semantics of this repository's GooseLang
  extensions (files, the network, durable state), each decision with its Go example in the
  extension's semantics examples package (CLAUDE.md, "Layout").
- Perennial's own models of the standard library (`.lake/packages/perennial`), trusted as Perennial.
