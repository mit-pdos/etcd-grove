# The gRPC KV service (etcd's server/v3/etcdserver/api/v3rpc): every linked result of
# Proof/go_etcd_io/etcd/server/v3/etcdserver/api/v3rpc/Link.lean and the results Results.lean prints.
#
#   etc/tcb-report.py --collection etc/tcb-collections/v3rpc.txt [--check [--update]]
#
# `roots PATTERN`: regular expressions selecting roots (etc/tcb-report.py --help);
# `axiom X`/`sorry X`: the baseline, written by --check --update.
# Unit 1 (2026-10-12): the package's proofs reach grpc's status errors and `errors.Is` at
# `context.DeadlineExceeded` (an empty struct, which Perennial's `errors.wp_Is` does not take);
# the txn package's `IsDefaultOrdering`/`HasRevisionFilters` and adt's intervals are proved, and
# the interval tree's contract (pending) is a hypothesis of `checkIntervals` and `Txn`, not an axiom.
# Unit 3a (2026-10-12): `put_end_to_end`/`deleteRange_end_to_end` (Results.lean) link the server's
# `EtcdServer.Put`/`DeleteRange`, so the collection reaches the request path's trust boundary too
# (the proposal's: otel, prometheus, traceutil, the transport queries, `MarshalIRR`, the context
# axioms, `errors.IsCtxErr`, the new `context.ErrDone`); the handlers' own results do not.
# Unit W-S (2026-10-14): the watch service (watch.go) adds mvcc's watch stream (its Link) and
# the watch path's trust boundary: `isClientCtxErr`, `math/rand.Int63n`, `(*time.Duration).Seconds`,
# zap's `NewNop`/`Debug`/`Duration`, verify's `Assert`, time's ticker (see watch.txt).
# The auth plan's E3y (2026-10-27): `userAdd_end_to_end_on` reaches bcrypt's hashing,
# `bcrypt.GenerateFromPassword` (the trust boundary, already in the repository's trust base). E3za
# (2026-10-27): `etcd_auth_served` serves the Auth service's methods over grpc's serving axioms
# (`grpc.serve`, `grpcServerAt`, `grpcServes`, `grpcServes_persistent`; `etcd_kv_served`'s, in the
# client's collection).
