# the txn package's `IsDefaultOrdering`/`HasRevisionFilters` and adt's intervals are proved, and
# the interval tree's contract (pending) is a hypothesis of `checkIntervals` and `Txn`, not an axiom.
# Unit 3a (2026-10-12): `put_end_to_end`/`deleteRange_end_to_end` (Results.lean) link the server's
# `EtcdServer.Put`/`DeleteRange`, so the collection reaches the request path's trust boundary too
# (the proposal's: otel, prometheus, traceutil, the transport queries, `MarshalIRR`, the context
# axioms, `errors.IsCtxErr`, the new `context.ErrDone`); the handlers' own results do not.

# zap's `NewNop`/`Debug`/`Duration`, verify's `Assert`, time's ticker (see watch.txt).
