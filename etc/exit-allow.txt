# The process and goroutine exits in the own code (under examples/) of the programs the robustness
# theorems are about, and the calls of wrappers that forward their arguments to one (etc/exit-check.py,
# etc/exitcheck). Under `Robust` an exit of any status is a safe run (Perennial models syscall.Exit as
# AngelicExit), so a check must panic on a violation, never exit. An entry is an exit that reports no
# check's failure: a command-line usage error before any check runs, an environment failure (a file or
# dial that fails), or one the deployment never takes (with why). A new exit needs an entry with a reason
# checked against the code; an entry nothing hits fails (stale).
