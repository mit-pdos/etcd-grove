# grpc's importable modules (phase7-seal, decision A of `notes/phase7-endstate.md`, 2026-11-26): what
# proofs outside grpc's tree may import (`etc/api-check.py etc/api/grpc.txt --check`). Every other module
# of the tree is internal. The address vocabulary is sealed (`@[no_expose]`): `grpcAddrAt`, `grpcSvcAt`,
# `grpcStreamSvcAt` (`InvGrpcWire`), `isGrpcRpcMd` (`InvGrpc`), `isGrpcStreamMd` (`InvGrpcStream`); a
# client uses their laws (`grpc_addr_set`, `grpc_addr_set_tok`, `grpcAddrAt_regCtx`, `grpcAddrAt_slots`,
# `grpc_listen_au`, `grpcSvcAt_of_addr`, `grpcSvcAt_mono_upd`, `isGrpcRpcMd_*`, `isGrpcStreamMd_*`).
# The connection protocols `grpcCliP`/`grpcSrvP` and the call protocol (`InvGrpcCallLib`) are sealed and
# not importable: rule 1 forbids `import all` of a module of the tree outside it.
#
# Started 2026-11-26 from what clients imported then and its public-import closure. Adding a module
# here is an API change.
