# structured-merge-diff v7.0.0's importable modules (review round 1 of the SMD API specs,
# 2026-11-19, notes/smd-plan.md): what proofs outside SMD's tree may import
# (`etc/api-check.py etc/api/smd.txt --check`). Every other module of the tree is internal. What
# each importable module exposes, as a client sees it, is `etc/gen-interface.py`'s output under
# `interface/`. Adding a module here is an API change: review its interface.
#
# The vocabulary modules (`Proof/.../v7/<pkg>/Defs.lean`) seal the representation predicates and
# their internals (`@[no_expose]`: `isIface`, `isValF`, `isSet`, `ownSet`, `isMF`, `isSchema`,
# `isTV`, `isUpdater`, ...); the pure vocabulary (values, paths, sets, schemas, the typed
# operations, `applyResult`/`updateResult`) stays exposed, so that `decide` evaluates it. The
# package's own proofs `import all` the Defs they unfold.
