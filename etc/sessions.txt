# The session registry of etc/gh-inbox.py (notes/coordination.md): who a `to:`/`from:` handle is.
# Replaces /shared/etcd-grove-sessions.md, which only one machine sees. One session per line,
# fields separated by `|`:
#
#   handle | owner | machine | GitHub account | claims | legacy signatures | legacy aliases
#
# - handle: what `to:` and `from:` lines name. A person is a row too (claim `human`):
#   `to: upamanyus` asks Upamanyu himself for a decision.
# - owner: the person the session works for. machine: where it runs (`-`: not recorded).
# - claims, comma-separated; the tool reads `human`; `relay` (also receives what is addressed to
#   its owner, and may answer for him); `queue` (runs the land queue and the build VM: land
#   requests and vm-build requests wait on it, and the tool reads its result posts);
#   `lands:<repo>` (lands collaborators' PRs of that repository, so they wait on it); `reviews`
#   (takes the review requests of its account). Other words are free text.
# - legacy signatures: the signatures the session ended its posts with before `from:` lines
#   (several separated by `||`). Read only at the end of a post without a `from:` line, to tell
#   the session's own old posts from others'.
# - legacy aliases: names others used for the session in prose before `to:` lines (`||`-separated).
#   They only make an old post addressed to the session; they never make a post the session's own.
#
# A session adds its row when it starts and removes it when it ends; each owner's coordinator keeps
# its sessions' rows.
