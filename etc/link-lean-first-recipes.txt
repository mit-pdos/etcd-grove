# The functions linked in `Proof/go_etcd_io/etcd/client/v3/experimental/recipes/Link.lean` (all
# Lean-first: no Rocq counterpart), read by `etc/gen-link.py --recipes`:
# `<fn>: <callees in the order of <fn>.wp_proof's hypotheses>`. The results are in the namespace
# `recipes` (`recipes.Queue.wp_Dequeue`); a clientv3 function's has the prefix `v3.`
# (`recipes.v3.wp_WithFirstRev`), concurrency's the prefix `concurrency.`
# (`recipes.concurrency.Session.wp_Client`).
#
# Every function of the package. Unit 1's (the options, key.go, client.go, watch.go) have their
# callees in the order of their `wp_proof`s' hypotheses; the others' lines are unit 0's FIRST
# GUESS (the functions each calls, in the order of the Go code, each once, at its first call),
# for units 2 and 3 to reorder. Until every function has a proof, the Link is generated with
# `etc/gen-link.py --recipes --skip-unproved`, which leaves out those with no proof file yet. Not listed:
# calls through interfaces (the client's `KV`, `Txn` and `Watcher` methods: the client bundle's
# contracts, not linked functions), a function's calls to itself (`newSequentialKV`,
# `Queue.Dequeue`, `PriorityQueue.Dequeue`, `DoubleBarrier.Leave`: the proof's own induction),
# and the standard library's functions with Perennial specs (`fmt.Sprintf`, `time.Now`,
# `Time.UnixNano`, `errors.Is`, `strings.Split`, `context.TODO`/`Background`/`WithCancel`).
# The promoted methods of `EphemeralKV` (`ek.Revision()`, `ek.Delete()`, `ek.Key()`) unfold to
# `RemoteKV`'s and are listed as those.
#
