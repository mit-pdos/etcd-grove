# etcd-io/etcd#21966: Panic in `IsLocalMemberLearner` when `Maintenance/Status` is called concurrently with member removal

- URL: https://github.com/etcd-io/etcd/issues/21966 (open; `type/bug`)
- Affected: `main` (reporter's Docker reproducer builds `main`; stack trace from 3.6.12's API module).
- Fix: none merged. PR #21967 was closed unmerged. PRs #22188 and #22205 are open: both make
  `IsLocalMemberLearner` return `false` instead of panicking.

What goes wrong: on the member being removed, the apply loop applies `ConfChangeRemoveNode` for
itself (`applyConfChange` → `RaftCluster.RemoveMember` deletes `c.members[localID]`). The server
stops only after the apply. In that window a gRPC `Maintenance/Status` handler runs
`maintenanceServer.Status` (`v3rpc/maintenance.go:270-282`). It calls `ms.cs.IsLearner()` →
`EtcdServer.IsLearner` (`server.go:2430`) → `RaftCluster.IsLocalMemberLearner`
(`membership/cluster.go:786-797`), which calls `c.lg.Panic("failed to find local ID in cluster
members")`. The process exits with code 2 instead of 0. The reporter's stack shows this caller.

## Classification

**O-fn (secondary A-pre).** The buggy code is at the pin: `IsLocalMemberLearner`'s `Panic` is
unchanged at `107edf7e4`. The decisive fact is that the path is unverified:
`maintenanceServer.Status` (v3rpc's `maintenance.go` is names-only), `EtcdServer.IsLearner` and
`IsLocalMemberLearner` are not translated. Where this repository does reach the same panic, through
the unary interceptor's `IsMemberExist(...) && IsLearner()`, the spec excludes it only by a premise
that this run violates: `membership.localKept c`
(`Proof/go_etcd_io/etcd/server/v3/etcdserver/api/membership/Defs.lean:99-106`, an axiomatized
predicate, "introduced by nothing"). That race is already recorded as
`issues/etcd-unary-interceptor-learner-removed.md`. This report is the same root cause through a
different, unguarded caller.

Source: `verified.txt` (scratchpad inventory at `d606c9cac`).

## The argument (step 4)

- The handler that panics in the report is not translated, so no spec covers it: O-fn.
- The verified neighbor shows why the proof does not catch the same race. `EtcdServer.IsLearner.spec`
  returns "some boolean" given `membership.isRaftCluster c ∗ membership.localKept c`. The premise is
  propagated to `newUnaryInterceptor.spec`, `newStreamInterceptor.spec` and the server's gRPC results
  (`Proof/.../api/v3rpc/Results.lean:729`). In the reported run the local member is removed while
  requests are being served, so `localKept` is false of the real server. The panic is excluded
  only by an assumption that is not met: A-pre, as a secondary class. The premise was introduced
  because of this panic, when unit P3b was proved (`notes/STATUS.md`, around line 5022).
- `maintenanceServer.Status` is worse than the interceptor: it calls `IsLearner()` with no
  `IsMemberExist` guard at all. A spec for it would need `localKept` outright.

Not X: no proved statement covers this caller, and the one that covers the interceptor states its
premise.

## Proposal: `drop-local-kept` (new)

Remove the `membership.localKept` axiom. Translate `RaftCluster.IsLocalMemberLearner` (13 lines) and
`IsMemberExist` and prove them against `isRaftCluster` with no premise on the local member. This needs
the upstream fix: `IsLocalMemberLearner` returning `false`, or `(bool, ok)`, for a missing member, as
in PR #22188 or #22205. At the pin the proof fails at the `Panic`, which is how the interceptor
instance was found. Then drop `localKept` from `EtcdServer.IsLearner.spec`, the two interceptors and
`v3rpc/Results.lean`. Also prove `maintenanceServer.Status` (about 35 lines; its other calls,
`raftStatus`, the backend sizes and alarms, are trust-boundary getters) so that the reported caller
is covered as well. Cost: small for the membership functions and the premise removal (mechanical
across the v3rpc results), small to medium with `Status`. At the pin it is blocked on the upstream
fix: proving it against the fork needs the fix applied there (a fork commit, as for other `issues/`
findings).
