# Artifacts for `etcd-io/etcd#22618` Verification

This directory contains reproduction and probe artifacts for the formal verification of [`etcd-io/etcd#22618`](https://github.com/etcd-io/etcd/pull/22618) (`cache: make the cache ready again after a watch retry`), documented in [`../etcd-22618.md`](file:///shared/etcd-grove-pr/etcd-22618/notes/pr-verify/etcd-22618.md).

## Contents

- [`repro_test_before.log`](file:///shared/etcd-grove-pr/etcd-22618/notes/pr-verify/etcd-22618/repro_test_before.log): Output of `go test -v -race -count=1 -run 'TestCacheReadyAfter(CompactionResync|WatchRetry)' .` in `cache/` with `c.demux.Init(rev)` moved back inside `readyOnce.Do(...)` in `Cache.watchEvents` (pre-PR behavior). Both `TestCacheReadyAfterCompactionResync` and the non-adjacent subtests of `TestCacheReadyAfterWatchRetry` fail because `c.demux.Init(rev)` purges the newly registered `storeW`, closing `applyErr` with `nil`, which causes `watchEvents` to call `c.ready.Reset()` and return `nil` while `Cache.watch` loops in-place with the already-spent `readyOnce`.
- [`repro_test_after.log`](file:///shared/etcd-grove-pr/etcd-22618/notes/pr-verify/etcd-22618/repro_test_after.log): Output of `go test -v -race -count=1 -run 'TestCacheReadyAfter(CompactionResync|WatchRetry)' .` on `pr-etcd-22618-goose-lean` (`53a9607c60ffb41d7be31af6545a440e3dd59e76`), showing all tests passing with `-race`.
- [`store_watcher_lag_probe_test.go`](file:///shared/etcd-grove-pr/etcd-22618/notes/pr-verify/etcd-22618/store_watcher_lag_probe_test.go): Standalone Go test (`TestProbeStoreWatcherLag`) demonstrating a related residual issue in `Cache.watch` / `Cache.applyStorage`: when `storeW` lags behind `d.history` (`nextRev < d.minRev`), `d.resyncLaggingWatchers()` calls `storeW.Compact(nextRev)` (closing `storeW.respCh`), `applyStorage(storeW)` returns `nil` (ignoring `storeW.cancelResp`), and `watchEvents` calls `c.ready.Reset()` and returns `nil` to `Cache.watch(rev)`, which loops in-place with the same `rev` (`< d.minRev`) and the already-spent `readyOnce`.
- [`store_watcher_lag_probe.log`](file:///shared/etcd-grove-pr/etcd-22618/notes/pr-verify/etcd-22618/store_watcher_lag_probe.log): Output of `go test -v -race -count=1 -run TestProbeStoreWatcherLag .` confirming `TestProbeStoreWatcherLag`.
