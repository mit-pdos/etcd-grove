# dsv-bufio: shared bufio for the dsverify kits (#24)

Branch `dsv-bufio` (worktree `/shared/etcd-grove-dsvbufio`, off `origin/lean` 2dce8dc601), the
dsverify-lab session's agent, 2026-11-23. The split agreed with Upamanyu on #24: widen the main
tree's `bufio` translation, generic specs over an `io.Reader`/`io.Writer` contract (nothing about
`net`), the connection's instances as laws in `Net/`.

## What is here

**Translation.** `Code/bufio.toml` now also translates `NewWriter`, `NewWriterSize`,
`Writer.{Flush,Available,Buffered,Size,Write,WriteByte,WriteString}`, `Reader.{ReadByte,ReadSlice,
collectFragments,ReadString,Buffered,Size}`, `NewReadWriter` (imports `bytes`, `strings` added).
Regenerated `Code/bufio.lean`, `GeneratedProof/bufio.lean`, `Proof/bufio/Init.lean` (gen-init) and
three PkgTables; `Proof/bufio/PkgInit.lean` imports `bytes`' and `strings`' package facts. Additive:
the existing WAL specs (`bufio.NewReader.spec`, `bufio.Reader.Read.spec`, over `io.readerStream`)
are unchanged.

**Contracts.** Reader: Perennial's `io.readerOk ri Pre S E`. Writer: `io.writerOk wi J Q Ew`
(`Proof/io/WriterOk.lean`, new; short writes, `Q` prefix-closed, errors with `Ew`'s evidence).

**Vocabulary** (`Proof/bufio/Own.lean`): `bufio.ownBufReader br ri Pre S E R` (returned `R`),
`bufio.ownBufWriter bw wi J Q Ew sent pend err`, `bufio.errE E` (adds `io.ErrNoProgress`),
`bufio.preUpTo`.

**Laws.** `bufio.ownBufReader_readerOk` (`Proof/bufio/ReaderLaws.lean`): a `*bufio.Reader` is an
`io.readerOk` reader, so Perennial's `io.wp_ReadFull`/`io.wp_ReadAtLeast` read through it.
`Net/Proof/net/ConnIo.lean`: `net.conn_readerOk` (`recvTokL cn s P` as the stream state, reads of
`len(p) > 0`), `net.conn_writerOk` (`sendTok cn s P`, `Q = P cn`, `ProtoPrefixClosed P`),
`net.connIface t`, `net.connReadE`, `net.connWriteE`, `net.connIface_ne_bufioReader/Writer`.
