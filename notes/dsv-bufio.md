# dsv-bufio: shared bufio for the dsverify kits (#24)

Branch `dsv-bufio` (worktree `/shared/etcd-grove-dsvbufio`, off `origin/lean` 2dce8dc601), the
dsverify-lab session's agent, 2026-11-23. The split agreed with Upamanyu on #24: widen the main
tree's `bufio` translation, generic specs over an `io.Reader`/`io.Writer` contract (nothing about

Verdict "revise before landing"; every item done except R5's `ReadString` (below). By item:

- **R1, one spec per function.** `bufio.preUpTo` is now an Iris predicate over the stream states,
  `bufio.preUpTo S Pre n := □ ∀ r, S r -∗ ⌜∀ m, 0 < m → m ≤ n → Pre r m⌝` (was the pure
  `∀ r m, 0 < m → m ≤ n → Pre r m`), held by the reader for its buffer; `Read` takes

  `bufio.walPre`), their proofs one call of `specE` each; the WAL's own proofs of `NewReader` and `Read`
