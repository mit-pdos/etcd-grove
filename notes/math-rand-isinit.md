# math-rand-isinit: `math/rand`'s `isPkgInit` is Perennial's `isInit` (2026-11-24)

Branch `math-rand-isinit`, **off `origin/lean` 7688316169 (Perennial pin fce59af75), independent of
`rand-retire`** (restructured 2026-11-24 evening; the earlier head `1cd81c4b8a`, based on rand-retire,
is superseded). Fixes the finding of `notes/dsv-instances.md` (branch `dsv-instances`, folded in
here) and of the #49 dsverify review: since Perennial 47ec64a9d translates `math/rand`'s
`Intn`/`Int63n` (they read the package variable `globalRandGenerator`), the main tree's
`isPkgInit math.rand := define_is_pkg_init iprop(True)` made every spec of them with precondition
`isPkgInit math.rand` (or none) unprovable: rabia's `math.rand.Hyps.Intn`, QuePaxa's
`raxos.hyp.RandHyp.Intn` were unsatisfiable. **SwiftPaxos had the same unsatisfiable premise** (it
takes rabia's class `math.rand.Hyps` and calls `Hyps.Intn` in `OrchParts.lean`), so it is fixed here
too; **gryff** took `math.rand.InitHyp` (satisfiable, now discharged).

## The finding, rechecked on lean 7688316169 (2026-11-24)

Checked in Lean (a scratch module importing `Dsverify.Proof.math.rand.Spec`, `Dsverify.Proof.raxos.Hyp`
**and** `Perennial.Proof.math.rand.Base`, built with the fce59af75 manifest, never committed;
`#print axioms`: Lean's three each): (1) `math.rand.Assumptions` unfolds `Intn` and `globalRand` to
their bodies (`h.Intn_unfold`, `h.globalRand_unfold`); (2) the `IsPkgInit (IProp GF) pkg_id.math.rand`
instance that elaborates there is the main tree's `mathRand_is_pkg_init_inst` (`rfl`), even with
Perennial's instance in scope; (3) its fact is `isPkgInitDef … = iprop(True)` (`rfl`). Inferred, not
proved in Lean: the premise is false of the body (it claims `Intn` safe from a state where
math/rand's initializer never allocated `globalRandGenerator`, whose atomic `Load` is then stuck);
no refutation `premise → False` was attempted.
