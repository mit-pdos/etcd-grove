## Goal
Replace hand-written trusted Lean of the standard library (Perennial) and of etcd-grove's `os`/`syscall`/`net`/...
with **Go model overlays** (perennial#692; plan in the appendix, `plan-go-models.md`, §6 stages S0–S7): the real Go
is translated wherever possible; otherwise a Go model declared in the package's `.toml` `[model]` table is spliced
into the real package and translated/verified like real code; only irreducible primitives stay Lean. S0 (mechanism)
and S1 (strings) are on Perennial lean. **Deliverable: ONE combined review packet for Upamanyu** covering S2–S7
(each model next to the real Go, which functions became real translations, new primitives, deleted trusted Lean,
premise/statement changes, `#print axioms`, Perennial `etc/trusted-delta.py`, etcd-grove `tcb-report` before/after).
Nothing trusted lands before he reviews it. Draft: `go-models-2026-11-24/packet-draft.md`.

## Rules in force (Upamanyu)
- Model ⊇ Go: a model must never be more defined than Go (return/succeed where Go panics, throws, blocks). Every
  `gomodel.Choose`/`Stuck` needs a reason in its `MODEL:` comment. Real Go > Go model > hand-written Lean.
- No new Lean axioms, no new top-level premises (spec preconditions of internal specs are fine). Statements change
  only by strengthening, except approved items.
- Overnight autonomy: decide per the rules, record (decision, why, alternatives), finish the work; trusted stays on
  branches. One combined packet.
- Builds on the VM (`/shared/tmp/vm/vmlake`, batch targets); locally only `etc/lean-check.py` on 1–2 files.
  No permission-prompting commands (no `rm -rf` of variable paths, no force-push, no `reset --hard`).
- Each finished package gets an independent adversarial review (`brief-adversarial-review.md`): a fresh agent
  tries to find a Go program where model and real Go diverge in the unsafe direction.

  functions trusted so gc runs the real one, and check each model's gc body against Go's own tests.
- Go refuses overlays of files beneath GOMODCACHE (non-local modules): such packages cannot take `[model]` yet.
- Perennial lean's `Perennial/Code/strconv.lean` is not a go1.26.11 regeneration: restore it after a regen.
- gen-init needs a Perennial checkout at the pin (`PERENNIAL_DIR`); Net/KvNet/Dsverify parts need their own Init
  copies (`NET_MAIN`).

- Helpers ran out of context every ~1–2 h on the os/net ports: give them a `--fetch`ed tree and `lean-check` so they
  see goals; keep units small.
