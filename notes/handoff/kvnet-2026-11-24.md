## Goal and decisions
- **Goal (Upamanyu, rule 42):** raft has two top-level robustness examples, `raft_kvnet_robust` (TCP,
  part `KvNet/`, `examples/raft/kvnet`) and kvudp (UDP, owned by the UDP lead, branch `kvudp/2026-11-24`,
  in the same Go package), plus the TLA trace-check theorems and kvwitness. kv, kvreconf and kvdurable
  (main tree and RaftNoAx's kvdurablenoax) retire once TCP ∪ UDP subsume them.
- **G1 (decided):** the axiom-free raft fork (raft-noax) is the headline raft.
- **G2–G4 (decided):**
  - Message duplication (G2), false snapshot failure (G3) and lossless reorder (G4) come from kvudp's
    UDP semantics. There is NO fault injection in kvnet's transport.
  - Analysis of TCP kvnet as is:
    - G2 is not covered.
    - G3 is covered via `closeAfter`'s timer race: a full frame is written, the timer fires before
      `disarm`, so the message is reported dropped though delivered. The report is ReportUnreachable
      plus SnapshotFailure; the unreachable part is a no-op in StateSnapshot.
    - G4 is covered only together with a spurious ReportUnreachable.
- **G5 (decided, DONE):** a replica's clean stop and in-process restart (raft's `node.Stop`).
  - Trigger: `ReqDisrupt` kind 3. The driver kvcheck picks it uniformly among 4 disruptions
    (`below(4)`), with no weighting, per the robustness skill `.claude/skills/robustness/SKILL.md`.
  - Path: `Node.restart` → `stopIncarnation` (`Replica.stop`: kvdurable's stop plus
    `dmu.Lock()` never released; then `Transport.stop`) → `start` (old StartNode body).
  - The transport is an interface `peerTransport` {start, Send, stop} with a constructor
    `newPeerTransport`. The contract is `PeerTransport.lean` (ptSend/ptStop/ptRunning/ptFresh/ptCtor
    with an address-premise parameter AP; TCP's is `tcpAP`). kvudp proves the same contract.
  - `isNodeS F rep stp nd γ N id` holds the incarnation under `Node.mu`, plus `stopLaw`/`startLaw` at
    a hidden R, so `Node.restart`'s proof is generic.
  - Design: `notes/kvnet-g5-stop.md`.
- **P8 (from the pure-premises plan, DONE on kvnet-single at the pickup; see the update below):** drop the configuration premises of
  `raft_kvnet_robust` by checking them in Go.
  - The Go side is done: RunNode/Check return instead of panicking; `MaxDirLen = 1<<39`; the P8
    helper's WIP also makes `AddrOk` reject `len(a) > 21`, which the canonical a.b.c.d:p never

  - Drop: `cl.Ok`, `n < 2^32`, `dir < 2^39`, `Nodup`, `addrOk`. Keep: `dir` is a root and empty

- **kvgen-names (UDP lead, merged):** kvGen claims only the storage file's names, so kvudp's boot-counter
