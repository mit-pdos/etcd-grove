## S1

`context.go:168`: `var Canceled = errors.New("context canceled")`. `context.go:176`:
`deadlineExceededError.Error()` returns `"context deadline exceeded"`. Neither error has
`GRPCStatus`, so `status.FromError` takes its `Error()`.

`TestS1CtxDescs` checks each description to equal the stated string on five paths:
- `Error()`;
- `rpctypes.ErrorDesc`;
- `status.Convert(e).Message()`;
- `status.FromContextError(e).Message()`, the server's path;
- the description a real grpc client receives from a handler returning `togRPCError(e)`, which
  passes the error through.

All pass.

**Consistency.** The field speaks of the values in `context`'s two cells, which `context`'s
initializer sets once (`↦□`). `errDesc` is opaque, so the field holds for any interpretation of
`errDesc` that maps those two values to their messages, which Go's does.

## S2

- **The literal.** `util.go:35-93` at the pin. `grpcErrKeyGlobals` is extracted from it in order:
  - membership: 6;
  - `etcdserver/errors`: 2 + 3 + 13 + 2;
  - mvcc: 2;
  - `version`: 3;
  - lease: 3;
  - auth: 17;
  - `context`: 2.

  Each name exists in the translation (`Code/…`, checked by script).
- **The domain.** A Go map literal stores every key. Duplicate keys at run time would only
  overwrite a value, and none are present (each key variable is a distinct `errors.New` or an
  `EtcdError`).
- **Nothing removes a key.** The map's only other use is the lookup at `util.go:103`: there is no
  `delete`, no assignment and no other reference in the pinned source.
- **The key variables do not change.** None is assigned outside its declaration in the non-test
  sources (grep over `server`, `api`, `client`; the one hit, `grpcproxy/cache.ErrCompacted`, is
  another package's variable). Package initialization runs every imported package first, so each
  key has its final value when the literal is built.
- **Consistency.** The wand needs the caller's `globalAddr g ↦□ k`, which can come only from `g`'s
  own package facts. The axiom therefore claims nothing about a cell it does not see, and agreement
  of `↦□` fixes `k` to the cell's one value.
