# Axiom soundness reviews

One report per review by the `axiom` skill (`.claude/skills/axiom/`): the axioms attacked, the
verdict, the counterexample (a Go program that panics and a Lean proof that it does not, from the
axioms) or every attack tried. The verdicts are also in `notes/audit.md`'s table.

| report | axioms | verdict |
|---|---|---|
| [bbolt](bbolt.md) | bbolt's key-value triples (`Spec/go_etcd_io/bbolt/*_kv.lean`), the predicate model (`InvBbolt.lean`), the `Options` rules, the package initializers | **refuted**: `ownWTxG_fill` (counterexample proved, 2026-10-29); `Put_kv` with `Commit_kv`/the cursor specs (by two earlier `issues/` reproductions) |
| [openbackend](openbackend.md) | `storage.OpenBackend` (and `OpenSnapshotBackend` through it), as restated on `backend-cmp` (`2e49ff1aa9`) | **refuted as documented** (counterexample proved, 2026-10-29): `dbOpensOk` is documented as an environment fact, but a `QuotaBackendBytes` above bbolt's `MaxMapSize` makes `Open` fail and `newBackend` panic in any environment; the restated `fkOwn γ (fkInit D)` (from `New`'s proved post) survives; **fixed** by `openMmapOk` in `openPre` (2026-10-29; on `lean` before the rest of `backend-cmp`) |
| [openbackend-post](openbackend-post.md) | `storage.OpenBackend` with `openMmapOk` and the post `… ∗ dlInit γ ∗ fkCl γ P D ∗ srSlot b` (`backend-cmp` at `aaa22d3714`) | **refuted as documented again** (counterexample proved, 2026-10-29, branch `axiom/openbackend-post`): `openMmapOk` bounds the mmap size by bbolt's `MaxMapSize` (256 TiB) but Linux amd64 gives a process 128 TiB of address space; a quota of `2^47` passes it and `mmap` fails (`ENOMEM`), `newBackend` panics. The new post (`fkCl`, `srSlot`, `dlInit`) survives: it is `New`'s proved post, and `openPre` maps onto `New`'s premise faithfully |
| [nocmpread](nocmpread.md) | `mvcc.kbNoCmp_metaNone` (`Proof/go_etcd_io/etcd/server/v3/storage/mvcc/NoCmpRead.lean`) | **refuted** (counterexample proved, 2026-10-29, on branch `axiom/kbnocmp-metanone`): the premise does not tie the reader to the backend (`L := False`), so one backend's no-compaction token says every reader finds no compaction, for good; Go's backend finds one after the store compacts. Its first proposed restatement is false too (direct `Meta` puts); **fixed on `backend-cmp`** by the compaction keys' tracked absence (the axiom deleted, `2e49ff1aa9`), not yet on `lean` |
| [outgoingOf-noValues](outgoingOf-noValues.md) | `metadata.outgoingOf_noValues` with `AppendToOutgoingContext`, `FromOutgoingContext`, `outgoingOf`/`mdAdd`/`mdNorm`, Perennial's `isContext` | **refuted**: inconsistent with `AppendToOutgoingContext.wp_proof` (`isContext` ignores `ContextDesc.Values`, so every context has a no-values descriptor); counterexample proved (2026-10-29) |
| [withtimeout-outgoing](withtimeout-outgoing.md) | `context.WithTimeoutBackground.wp_proof` (its new `outgoingOf ctx' = none` conjunct) with `AppendToOutgoingContext`, `FromOutgoingContext`, `withVersion`, `outgoingOf`, grpc's attempt contract, every `Spec/context/` spec | **survives** (2026-10-29; not taken: the conjunct is `WithTimeoutBackgroundMd`'s, the base stays proved): true of Go (a fresh `*timerCtx` over `Background()`, whose `Value` is nil at grpc's key); no spec equates its result with a context with metadata |
| [snapshot](snapshot.md) | `backend.backend.Snapshot` (D22's, as restated by the backend stage's question 2 on `backend-cmp`, `45977a5725`: `viewAt` the logical view) | **survives** (2026-10-29): every commit before `Begin(false)` ends with the batch lock's shares at the committed data and `W ∗ Pk` held while the caller holds `R`; the four commit kinds, a compaction's pending and committed deletes, the hook and tracked-bucket halves, vacuous observations, a stopped backend; defrag out of scope |
| [etcd-noOtherRefusal](etcd-noOtherRefusal.md) | `etcd_noOtherRefusal` (F-S2 part 1; added 2026-10-29) | **survives** under the voter condition (as `etcd_noRefusal`); no auth-on path yields the three descriptions (2026-10-29) |
| [withtimeout-md](withtimeout-md.md) | `context.WithTimeoutBackgroundMd` (auth-5b, `189a0bfae4`): `WithTimeoutBackground` plus `outgoingOf ctx' = none` | **survives** every attack tried; caveat: `outgoingOf` is a function of values under nondeterministic allocation (shared with `AppendToOutgoingContext`) (2026-10-29) |
| [g2-newstream](g2-newstream.md) | G2's `grpc.ClientConn.NewStream` (md-indexed, `clientAttemptMd`/`grpcAttemptMd`) and `NewClient`'s `dialOk` (a stream interceptor present), `g2-stmts` `7ec9f1f715` | **refuted**: NewStream (counterexample proved, 2026-10-30): grpc's server deletes `"host"` from the handler's metadata (`:authority` present, gRFC A41), which `grpcReservedKey` did not exclude; the same of the unary `grpcInvokerOk`. Repaired: `"host"` a reserved key. `dialOk` survives |
| [g2-servestream](g2-servestream.md) | G2 (b) `grpc.serveStream`'s md-indexed contract and (b′) `srvStreamInterceptorOk` with `grpc_prometheus.ServerMetrics.StreamServerInterceptor` (`7ec9f1f715`) | (b′) **survives**; (b) **refuted on the Go side** (Lean proof not built), the same `host` flaw as g2-newstream, repaired with it (2026-10-30) |
| [g2-streamkey](g2-streamkey.md) | `clientv3.streamKeyFromCtx` (G2's (c), `7ec9f1f715`), `streamKeyOf_none`, `streamKeyOf_single`, with `AppendToOutgoingContext` and `outgoingOf` | **refuted jointly**: `streamKeyOf_single` with `AppendToOutgoingContext.wp_proof` at non-ASCII keys (Lean theorem); `streamKeyOf_single` false at `v = ""` (latent). Repaired: `lowerKey` ASCII, `v ≠ ""`. `streamKeyOf_none` and `streamKeyFromCtx`'s return ok (2026-10-30) |
| [g2-withcancelvalctx](g2-withcancelvalctx.md) | `context.WithCancelValCtx.wp_proof` as strengthened by G2's (h) (`7ec9f1f715`) | **survives** (2026-10-30): `valCtx` promotes `inctx`'s `Value`, a `*cancelCtx` delegates every key but `&cancelCtxKey`, so grpc reads the same `rawMD` |
| [marshalirr-keys](marshalirr-keys.md) | `proto.MarshalIRR.wp_proof`'s `irrKeysLe bs.length rq'` conjunct (`0d43bc2dd8`, branch `invoke-size`) | **survives** (2026-10-31): a fact of every successful protobuf decoding (each key a contiguous sub-range of `bs`); `bs` is the slice checked against `MaxRequestBytes` and proposed; independent of the depth finding |
