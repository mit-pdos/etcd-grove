# Journal

Append-only log, one file per day: `YYYY-MM-DD.md`. Multiple sessions on the
same day append to the same file under their own `##` heading.

This is for archaeology, not orientation — a fresh agent should read
`../STATUS.md` first and come here only to answer "how did this get this way?"

Never rewrite history here. If an entry turns out to be wrong, say so in a
later entry.

## Entry template

```markdown
## <what the session was about>

**Agent:** <model/agent, or a person's name>

- **Did:** what changed, with paths.
- **Learned:** anything surprising. Link to the `topics/` or `gotchas.md` entry
  if it earned one.
- **Dead ends:** what was tried and did not work, and why. Do not skip this.
- **Left:** state at the end — what builds, what doesn't, what's half-done.
```
