# Non-issues

The findings without a valid failing Go test: found by code reading, unstated preconditions etcd
meets, documentation findings, behavior etcd does not guarantee, test-helper bugs, tests that fail
only by using an internal API in a way no etcd caller does. They are recorded because a proof may
rest on them (`blocks-proof`, and the premise that cites the file) and because some may become
issues: a finding moves to [`../issues/`](../issues/README.md) when someone writes a valid failing
test for it.

The format is [`../issues/README.md`](../issues/README.md), "A non-issue"; the list is
[INDEX.md](INDEX.md), generated by `etc/issues-status.py --index`.
