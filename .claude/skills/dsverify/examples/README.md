# Reviewed specs

One file per spec the user reviewed: its first version, each critique with what it changed, and the
approved version. Reviewers read these with `PRINCIPLES.md`. Starts empty; add one each time the user
approves a spec, and cite the file from the principle it illustrates.

Format:

```markdown
# <function or predicate>

## First version
<the statement>

## Critique 1 (<who>, <date>)
<what was wrong, which principle>
→ <what changed>

## Approved
<the statement>
```
